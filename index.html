Allgemein & Prüffristen

Geräte mit Haken bei „Bürogerät“ bekommen automatisch die Büro-Frist, alle anderen die Standard-Frist. Pro Gerät kann zusätzlich eine eigene Frist eingetragen werden.

Messgerät
QR-Code-Inhalt

Leer = der QR-Code enthält nur die Inventarnummer. Er bleibt dadurch sehr klein und ist auch auf 18-mm-Band sicher lesbar – gescannt wird mit dem Scanner dieser Seite. Mit Adresse (z. B. https://dguv-lw.web.app) öffnet auch die normale Handy-Kamera direkt die Gerätekarte; der Code wird dann aber dichter. Bereits geklebte Etiketten funktionieren in beiden Fällen weiter.

Grenzwerte (DIN VDE 0701-0702 / DIN EN 50678 & 50699)

Einrichtung (Firebase)

  1. In der Firebase-Konsole ein neues Projekt anlegen (z. B. „dguv-lw“), Analytics kann aus bleiben.
  2. Authentication → Anmeldemethode E-Mail/Passwort aktivieren. Unter „Users“ dein eigenes Konto anlegen.
  3. Firestore Database anlegen (Standort europe-west3 Frankfurt). Unter „Regeln“ die Regeln unten einfügen und veröffentlichen.
  4. In Firestore die Sammlung benutzer anlegen, Dokument-ID = deine E-Mail (kleingeschrieben), Felder rolle = pruefer und name = dein Name.
  5. Projekteinstellungen → „Meine Apps“ → Web-App hinzufügen → die Werte aus firebaseConfig oben in dieser Datei bei FIREBASE_KONFIG eintragen.
  6. Für die Handykamera die Datei per Firebase Hosting (oder einem anderen https-Webspace) bereitstellen.
